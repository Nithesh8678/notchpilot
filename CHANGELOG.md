# Changelog

## 0.1.0 — initial development release

- Native menu-bar application and nonactivating notch/fallback overlay.
- Configurable global shortcut, toggle/hold sessions and immediate cancellation.
- Local progressive Apple speech pipeline and clause-level deterministic routing.
- Guarded WhatsApp adapter, private aliases, Dry Run and confirmation policy.
- MLX port of the local Laya decision model, reference parity tests and CPU/GPU benchmarks.
- General application launching, safe semantic desktop controls, folders, URLs and volume.
- Repair for stale macOS Accessibility approvals after ad-hoc rebuilds.
- Recoverable action errors keep speech active; punctuation revisions remain idempotent.
- Native and Python tests, packaging scripts, CI and privacy documentation.

See the README and acceptance report for verified behavior and remaining limitations.
